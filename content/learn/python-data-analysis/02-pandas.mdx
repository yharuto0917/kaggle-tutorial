## DataFrame とは

pandas の `DataFrame` は、表形式データを扱うための中心的なデータ構造です。
行（レコード）と列（特徴量）からなり、Kaggle のテーブルデータ分析の土台になります。

```python
import pandas as pd

df = pd.read_csv("/kaggle/input/titanic/train.csv")

# 列の選択とフィルタリング
women = df[df["Sex"] == "female"]
print(women["Survived"].mean())
```

## 欠損値の確認

データ分析の最初のステップは欠損値の把握です。

```python
# 列ごとの欠損数
df.isnull().sum().sort_values(ascending=False)
```

## 集計

`groupby` でカテゴリごとの集計ができます。

```python
df.groupby("Pclass")["Survived"].mean()
```

生存率の比較から、客室クラス（`Pclass`）が予測に効きそうだと分かります。
特徴量の重要度はおおまかに $\text{重要度} \propto$ 目的変数との関連の強さ、と捉えられます。

<Callout type="tip">
	`groupby` の結果はそのまま棒グラフにすると、カテゴリごとの傾向を直感的に掴めます。
</Callout>
